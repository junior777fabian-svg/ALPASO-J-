# Reportes del agente local

Aquí guarda sus resultados el agente que trabaja en la laptop del dueño, uno por parte: `etapa-0.md`, `etapa-1a.md`, y así. Las capturas de pantalla van en una carpeta con el mismo nombre, por ejemplo `etapa-1a/`.

Las instrucciones de cada parte están en [`docs/pruebas-locales/`](../docs/pruebas-locales/).

Este repositorio puede ser público. Los reportes no deben incluir correos, nombres, contraseñas, llaves, números de serie ni direcciones IP.
